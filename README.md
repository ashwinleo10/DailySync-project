# DailySync

**A Task Management Application built with React and Vite.**

DailySync helps users organize their daily tasks and stay productive.

## 🚀 Live Demo

**[View DailySync Live](https://ashwinleo10.github.io/DailySync-project/)**

## Features

- Create and manage daily tasks
- Track task progress
- Organize tasks efficiently

## Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Linting:** Oxlint

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ashwinleo10/DailySync-project.git
```

Navigate to the project folder:

```bash
cd DailySync
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## React + Vite

This project uses Vite for fast development and Hot Module Replacement (HMR). The official React plugins include `@vitejs/plugin-react` and `@vitejs/plugin-react-swc`.
